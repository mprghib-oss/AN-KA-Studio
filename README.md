# ANHKA Studio — Simple Clean Portfolio

Static website: HTML + CSS + JavaScript. No build step or framework required.

## Open locally
Double-click `index.html` or open it in a browser.

## Publish for free with GitHub Pages
1. Create a GitHub account.
2. Create a new **public** repository, e.g. `anhka-studio`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. In the repository go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide your public `github.io` address.

## Replace the demo project visuals
The current project blocks use CSS gradients so the site works immediately without image files.
To use real project photos, replace each `.project-image` with an `<img>` element and add your images to an `images/` folder.

## Customize
- Studio name: edit `ANHKA` in `index.html`.
- Email: replace `hello@anhka.studio`.
- Projects: edit titles, locations and years.
- Colors/spacing/type: edit `style.css`.
